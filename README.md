## 🌟 Overview

**Silent Guard** is an advanced personal safety application designed to protect you in emergency situations. With discreet, powerful features that work silently in the background, Silent Guard ensures you're never alone when you need help the most.

---

## 🚀 Features

### 🎤 Voice Command Triggers
- **Hands-free emergency activation**
- Say "help" or "sos" to trigger alerts instantly
- Works even when your phone is locked

### 🔊 Volume Button SOS
- **Discreet activation method**
- Press volume button 3 times rapidly
- No need to unlock your device

### 🔐 Wrong Password Detection
- **Anti-theft protection**
- Captures intruder selfies
- Alerts emergency contacts automatically

### 📞 Emergency Contacts
- **Manage your trusted circle**
- Add, edit, and remove contacts easily
- Contacts receive SMS alerts with location

### 📍 Location Sharing
- **Real-time GPS tracking**
- Automatic location sharing via SMS
- Precise location details for emergency responders

### 📸 Selfie Capture
- **Security monitoring**
- Intruder documentation
- Evidence collection

## 🛠️ Installation

### Prerequisites
- Android Studio Hedgehog or later
- JDK 17 or higher
- Android SDK API 26 or higher
- Firebase account (for authentication and database)

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/siddhtyagi18/SilentGuard.git
   cd SilentGuard
   ```

2. **Open in Android Studio**
   - Launch Android Studio
   - Select "Open an Existing Project"
   - Navigate to the cloned directory

3. **Set up Firebase**
   - Create a Firebase project at [firebase.google.com](https://firebase.google.com)
   - Add an Android app to your project
   - Download `google-services.json` and place it in the `app/` directory

4. **Build and run**
   - Sync Gradle files
   - Connect an Android device or start an emulator
   - Click the Run button or use:
     ```bash
     ./gradlew installDebug
     ```

## 💡 Usage

### Getting Started
1. **Create an account** or log in with existing credentials
2. **Add emergency contacts** who will receive your alerts
3. **Enable desired features** (voice triggers, volume SOS, etc.)
4. **Grant necessary permissions** when prompted

### Emergency Activation
- **Voice**: Say "help" or "sos" clearly
- **Volume**: Press volume button 3 times quickly
- **App**: Long-press the SOS button on the home screen
